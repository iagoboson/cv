# Personal CV Website

A lightweight multipage résumé website built with semantic HTML and published through GitHub Pages.

## Purpose

This project was created to practice structuring and publishing a personal website without a frontend framework.

## Pages

- Professional overview and experience
- Contact information
- Personal interests

## Stack

- HTML5
- GitHub Pages

## Run locally

No build step is required. Clone the repository and open `index.html` in a browser.
